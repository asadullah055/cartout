# Noto Serif Bengali

Self-hosted Bengali subset of Noto Serif Bengali, a variable WOFF2 font with weights 100–900.

- Font: https://fonts.google.com/noto/specimen/Noto+Serif+Bengali
- Authors: The Noto Project Authors (https://github.com/notofonts/bengali)
- License: SIL Open Font License 1.1, included in `OFL.txt`.
- Download source: https://fonts.gstatic.com/s/notoserifbengali/v31/hYkhPvggTvnzO14VSXltirUdnnkt1pwmWrprmO7RjE0a5BtdKyg8JCJZ.woff2

`app/globals.css` restricts this font to Bengali characters, Bengali punctuation and shaping helpers with `unicode-range`. Latin letters and ASCII numbers keep the existing English font. The font is served from this site without a runtime Google Fonts request.
